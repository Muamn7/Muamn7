# قريب — مراسلة بين الأصدقاء بدون إنترنت

تطبيق أندرويد للدردشة بين هواتف قريبة من بعضها **بدون إنترنت وبدون رصيد بيانات
وبدون أي خادم**. الهواتف تتكلم مع بعضها مباشرة عبر شبكة Wi-Fi محلية.

## كيف تستخدمه

1. **شخص واحد** يفتح «نقطة الاتصال» (Hotspot) في هاتفه. لا يحتاج رصيد بيانات،
   ويمكنه إطفاء بيانات الجوال تمامًا.
2. **الباقون** يتصلون بشبكته من إعدادات Wi-Fi. إذا ظهرت رسالة «لا يوجد اتصال
   بالإنترنت»، اختر **البقاء متصلًا**.
3. الجميع يفتح **قريب** ويكتب اسمه أول مرة، وبعدها يظهر الأصدقاء تلقائيًا خلال
   ثوانٍ.

يعمل أيضًا إذا كنتم جميعًا على نفس الراوتر، حتى لو لم يكن فيه إنترنت.

إذا لم يظهر صديق تلقائيًا (بعض الشبكات تمنع البث): من القائمة اختر
**«اتصال يدوي بعنوان»** واكتب «عنوانك» الظاهر أعلى شاشته.

## ما الذي يفعله

| الميزة | التفاصيل |
|---|---|
| **المجموعة** | محادثة تجمع كل الأصدقاء القريبين |
| **محادثات خاصة** | تصل فقط للشخص المقصود، ولا تمر بهواتف الآخرين |
| **علامات التسليم** | 🕓 بانتظار التسليم · ✓ أُرسلت للمجموعة · ✓✓ وصلت لصديقك |
| **رسائل مؤجلة** | الرسالة الخاصة لصديق غير متصل تبقى في هاتفك وتُرسل له تلقائيًا عندما يقترب |
| **اللحاق بالمجموعة** | من ينضم متأخرًا يستلم آخر 200 رسالة من المجموعة |
| **القفز عبر الأصدقاء** | رسالة المجموعة تنتقل عبر صديق في المنتصف لمن لا يصله الإرسال مباشرة |
| **يعمل في الخلفية** | الرسائل تصل والشاشة مطفأة، مع إشعار لكل رسالة |
| **حفظ المحادثات** | السجل يبقى بعد إغلاق التطبيق |

## المدى

بقدر مدى الـWi-Fi: تقريبًا **30 إلى 50 مترًا** داخل المباني وأكثر في الأماكن
المفتوحة. نقطة اتصال الهاتف تقبل عادة **8 إلى 10 أجهزة**.

## حدود يجب أن تعرفها

- **الرسائل غير مشفرة.** أي جهاز على نفس الشبكة يستطيع نظريًا التنصت عليها.
  استخدمه بين أصدقاء على شبكتكم الخاصة، لا على شبكة مقهى عامة.
- **أندرويد فقط.** آيفون غير مدعوم حاليًا.
- **نص فقط**، بلا صور أو ملفات صوتية في هذا الإصدار.

## التثبيت

كل دفعة (push) تبني ملف APK على GitHub Actions في سير العمل **Qareeb APK**:
افتح آخر تشغيل ← **Artifacts** ← `qareeb-release-apk`. أو شغّل سير العمل يدويًا
مع تفعيل **publish** لنشر نسخة (Release) يمكن تنزيلها مباشرة من الهاتف.

يتطلب أندرويد 8.0 فأحدث.

## للمطورين

```
qareeb/
├── core/   الشبكة والتخزين — جافا عادية بلا أندرويد، مع اختبارات
└── app/    واجهة أندرويد والخدمة
```

```sh
cd qareeb
./gradlew :core:test        # يعمل بدون Android SDK
./gradlew :app:assembleDebug  # يحتاج Android SDK (ANDROID_HOME أو local.properties)
```

**البروتوكول:** كل هاتف يبث `QAREEB1` على UDP منفذ 47801 كل ثانيتين. عندما
يسمع هاتفان بعضهما يفتحان اتصال TCP واحدًا على المنفذ 47800 (صاحب المعرّف
الأصغر هو من يتصل، حتى لا يُفتح اتصالان). السطور نصية مفصولة بـTab:
`HELLO` للتعارف، و`MSG` للرسائل، و`ACK` لتأكيد استلام الرسالة الخاصة، و`PING`
كل 5 ثوانٍ. الاتصال الذي يسكت 20 ثانية يُعتبر مغلقًا.
