## محتويات المجلد

| الملف | الوصف |
|---|---|
| `mobile_communications_sign.blend` | ملف بلندر جاهز: كل القطع، الخامات (الألوان)، الإضاءة والكاميرات |
| `stl_full_size/` | ملف STL لكل قطعة بحجمها الكامل (54 قطعة) – للطابعات الكبيرة |
| `stl_split_256mm_bed/` | نفس القطع، والكبيرة منها مقسّمة بحيث تكون كل قطعة ≤ 250 مم (Bambu / Prusa MK4 / ...) |
| `PARTS.md` | جدول القطع: اللون، المقاسات، عدد الأجزاء |
| `build_sign.py` | سكربت بايثون يبني النموذج كاملاً من الصفر داخل بلندر (قابل للتعديل) |
| `fonts/` | الخطوط المستخدمة (Nunito و Roboto – رخصة OFL مجانية) |

## المقاسات
* **الارتفاع الكلي: 600.0 مم** (من أسفل القاعدة الخشبية إلى أعلى السحابة)
* العرض: 674 مم – عمق القاعدة: 193 مم
* الوحدات في بلندر: **ملّيمتر** (1 وحدة = 1 مم) – ملفات STL بالملّيمتر مباشرة

## طريقة البناء (طبقات مثل الصورة تماماً)
النموذج ليس كتابة فقط، بل لوحة طبقات بارزة وفيها عناصر مجسّمة:
1. **اللوح الكحلي** (10 مم) + **إطار أزرق فاتح** خلفه (8 مم) يظهر كحافة حول اللوح
2. **السحابة الكبيرة**: حدّ أزرق (10 مم) + سطح أبيض (5 مم) + عنوان بارز (5 مم) + موجات الإشارة الكحلية
3. **البرج الشبكي** الأسود مع خلفية فاتحة داخله، والكرة في الأعلى، وأقواس الإشارة الزرقاء
4. **الجوال**: جسم أسود بارز 22 مم بحواف مدوّرة، شاشة، أعمدة الشبكة، 5G، أيقونة الاتصال
5. **سحابة Stay Connected** مع القلب
6. **الطبق اللاقط (Dish)** مجسّم حقيقي (قطع مكافئ) مع الذراع والكرة والحامل
7. **4 بطاقات** جانبية بإطار أزرق وأيقونات ونص
8. **النجوم** و**أعمدة الإشارة** السفلية
9. **قاعدة خشبية** فيها مجرى (Slot) يدخل فيه اللوح 10 مم

كل قطعة مستقلة ومغلقة (Manifold / Watertight) وتم فحص أنه لا توجد أي قطعتين متداخلتين،
لذلك القطع تتركّب فوق بعض بدون تعديل.

### اللوح الشفاف `Backer_Clear`
أقواس الإشارة حول البرج تطلع فوق اللوح (معلّقة في الهواء في الصورة)، فأضفت لوحاً رقيقاً
3 مم خلفها يُطبع بـ **PETG شفاف** ويُلصق خلف الإطار، فيمسك الأقواس وقمة البرج. إذا ستعلّق
اللوحة على الجدار تقدر تستغني عنه وتلصق الأقواس على الجدار مباشرة.

## إعدادات الطباعة المقترحة
* المادة: PLA (Matte أجمل لأنه يعطي نفس شكل الصورة)، الشفاف PETG
* ارتفاع الطبقة 0.2 مم – Infill 15% – جدران 3
* **القطع المسطحة**: اطبعها نائمة على ظهرها (الوجه البارز للأعلى) – بدون دعامات
* **النصوص والأيقونات** الصغيرة: ارتفاع طبقة 0.12–0.16 مم لدقة أعلى
* **الطبق Dish_Bowl**: اطبعه وفتحته للأسفل مع دعامات Tree
* الكرات (`Dish_Feed_Ball`): مع دعامات بسيطة
* الطابعات متعددة الألوان (AMS): استورد كل ملفات المجموعة معاً → Bambu/Orca يسألك
  «Load as single object with multiple parts» → نعم؛ لأن كل الملفات بنفس الإحداثيات فتتركب تلقائياً.

## التركيب (الترتيب)
1. ألصق قطع اللوح الكحلي المقسّمة، ثم ألصق الإطار الأزرق خلفه – **خطوط التقسيم متعاكسة**
   بين الطبقتين، فكل طبقة تقوّي فواصل الطبقة الأخرى.
2. ألصق حدود السحب والبطاقات والبرج والجوال على اللوح، ثم الطبقات البيضاء/الفاتحة فوقها،
   ثم النصوص والأيقونات.
3. ركّب الطبق: الحامل على القاعدة ← الطبق ← الحافة البيضاء ← الذراع ← الكرة.
4. أدخل اللوح في مجرى القاعدة (تسامح 0.25 مم) وثبّته بالغراء.

لاصق مقترح: غراء CA (سوبر جلو) للقطع الصغيرة، وإيبوكسي أو لاصق PLA للقطع الكبيرة.

## التعديل داخل بلندر
* افتح `mobile_communications_sign.blend` – القطع مرتبة في Collections حسب اللون (`PRINT_PARTS/Color_*`).
* المشهد `PREVIEW_SCENE` (الجدار والطاولة والإضاءة) للعرض فقط، لا يُطبع.
* لتغيير الارتفاع أو أي مقاس: افتح `build_sign.py` في تبويب Scripting، غيّر مثلاً
  `TOTAL_HEIGHT = 600.0` أو `BED = 250.0` (لطابعة 220 مم ضع 210)، ثم Run Script.
  السكربت يعيد البناء ويصدّر ملفات STL من جديد (يحتاج مكتبة `shapely`
  وسيثبّتها تلقائياً في بايثون بلندر أول مرة).
* تشغيل بدون واجهة:
  ```bash
  blender -b -P build_sign.py -- --render
  ```
